# Тетрадь по кибернетике

Интерактивный курс, который читается как тетрадь, работает без сети и
проверяется целиком — от разбора схемы блока до клика по ссылке внизу
страницы на телефоне.

```
npm ci
npm run dev            # разработка
npm test               # модульные проверки
npm run e2e            # сквозные, на двух профилях: ладонь и стол
npm run faro           # оценки Lighthouse по собранному сайту
npm run scorrimento    # цена прокрутки пальцем на телефоне
npm run build          # сборка + связка с приложением + служитель
node scripts/caratteri.mjs   # пересобрать урезанные шрифты (сеть + Python)
```

Сквозные проверки идут по **собранному** сайту, а не по dev-серверу: офлайн,
служитель, отложенные куски и отпечатки в именах существуют только после
сборки, и проверять их на dev-сервере — значит проверять другую программу.

---

## Из чего это состоит

```
src/core/schema.ts        проверка данных: адрес беды и все беды разом
src/content/registry.ts   реестр блоков — единственная точка расширения
src/content/model.ts      курс: модули, темы, витки спирали
src/content/graph.ts      связность, порядок спирали, наследование целей
src/content/inline.ts     разметка строки и адреса витков
src/engine/assessment.ts  виды вопросов и их оценка
src/engine/progress.ts    опыт, звания, сроки повторения
src/engine/sessione.ts    сведение оценок за работы витка в одну
src/blocks/               что автору можно написать в лекции
src/widgets/models/       расчёт приборов — без DOM и потому в тестах
src/widgets/              сами приборы, элементы Lit
src/pages/                маршруты, построенные из учебного плана
src/courses/              содержание
scripts/offline.mjs       служитель и значки по описи собранного
scripts/twa.mjs           связка сайта с приложением Android
scripts/caratteri.mjs     урезание шрифтов до знаков, которые встречаются
scripts/glifi.mjs         какие это знаки
scripts/faro.mjs          прогон Lighthouse с порогом
scripts/scorrimento.mjs   цена прокрутки пальцем, с порогом
```

## Решения, которые стоит знать до правки

**Реестр — настоящая точка расширения.** Схема лекции строится **из** реестра,
а не из списка в движке. Ни маршрут, ни отображение лекции, ни галерея не
знают ни одного вида блока в лицо. Новый интерактив стоит ровно трёх вещей:
схема, элемент, одна регистрация. За тем, чтобы это осталось правдой, следят
тесты в `src/content/registry.test.ts`.

**Список островов литеральный, и это вынужденно.** Собиратель обязан увидеть
каждый `import()` глазами, чтобы выделить отдельный кусок; построить список
циклом по реестру нельзя. Поэтому `src/scripts/isole.ts` выглядит
однообразно, и поэтому же за его расхождением с реестром следит отдельный
тест — в обе стороны.

**Приборы — не острова Astro.** Интеграции `@astrojs/lit` здесь нет намеренно:
она кладёт в голову каждой страницы шим для declarative shadow DOM ради
приборов, которых на большинстве страниц нет. Приборы включаются
собственным наблюдателем по пересечению, с запасом в пол-экрана.

**Место под прибор занимается заранее.** Прибор оживает под самым пальцем, и
если он занимал сотню пикселей, а стал занимать четыре сотни, текст уезжает
ровно в тот момент, когда читатель до него добрался. Числа в `reserve`
измерены на собранном сайте в двух профилях.

**Страница обязана быть целой без единого скрипта.** Лекция, цели, оглавление
спирали, переходы — всё приезжает разметкой. Скрипты добавляют приборы и
счёт, и обе проверки «без JS» в `e2e/` стоят там именно за этим.

**Прогресс никуда не уезжает.** Он лежит в `localStorage` и переносится между
устройствами выпиской — сервера у тетради нет и не предполагается.

## Скорость и шрифты

Все четыре оценки Lighthouse — сотни, на всех видах страниц и в обеих
сборках (на корне и с префиксом `/Courses/`). Это не разовое достижение, а
проверка: `scripts/faro.mjs` падает, если хоть одна оценка ниже сотни, и
стоит в потоке выкладки рядом со сквозными.

**Шрифты урезаны до знаков, которые в тетради встречаются** — 352 КБ стали
98 КБ. Три решения, каждое измерено:

- Набор просится у Google целиком (`text=`), а не по блокам Юникода. Русской
  странице нужны сразу кириллица, латиница и греческий; по блокам это три
  файла на каждое начертание, одним запросом — один.
- Файл делится не по блокам, а по частоте: `-sempre` (кириллица, цифры,
  знаки) нужен всегда и предзагружается; `-raro` (латинские буквы,
  греческие, математические) приезжает, только если такой знак встретился.
  У Caveat деления нет намеренно — см. комментарий в скрипте.
- Из накладных возможностей оставлен кернинг. `calt` тянет за собой
  альтернативные начертания каждой буквы: кириллический Caveat из-за них
  весит 38 КБ вместо 15 при тех же 69 знаках.

**`font-display` у двух половин разный.** `-sempre` — `optional`: они
предзагружены, укладываются в отведённые сто миллисекунд и рисуют текст
сразу собой; не уложились — страница целиком набирается запасным и уже не
меняется. При `swap` каждый файл, приехав, подменял бы шрифт под уже
прочитанным текстом. `-raro` — `swap`, по обратной причине: это единичные
знаки, и латинская буква посреди рукописного слова, набранная не рукописным,
заметнее короткой подмены.

**Греческий и математические знаки появились впервые.** Их не было ни в
одном наборе: λ, ρ, Σ, ≈, ≤, ∫, ∞, стрелки и подстрочные цифры рисовались
системным шрифтом посреди формулы, набранной своим. Теперь их несёт узкая
накладка из Noto Serif и Noto Sans Math — два файла общим весом 1,7 КБ.

**Ничего не съезжает.** `e2e/stabilita.spec.ts` грузит страницы с холодным
кэшем и вчетверо замедленным процессором и считает сдвиги: порог 0,01 при
нормативных 0,1. Проверка нашла три причины, которых не видно ни в
исходниках, ни на быстрой машине: полоса состояния, раздвигавшая шапку;
высота шапки, взятая из шрифта; и приборные числа в переносимой строке —
«19.55°» становилось «9.5°», ряд то влезал, то нет, и текст под прибором
прыгал по нескольку раз в секунду.

**Прокрутка пальцем не платит за бумагу.** Освещённый лист однажды утопил
листание на телефоне: 46 мс на кадр вместо 17 и три четверти кадров длиннее
32 мс. Причин было четыре, и все — не в вёрстке:

- две живые переменные CSS писались каждый кадр в обёртки над всем
  содержимым, и каждая запись обесценивала стили всего документа: 1,57 с
  пересчёта против 0,19;
- фильтр смещения — то, что и ведёт буквы, — работал во весь экран и во
  время пролистывания, когда по летящему тексту его всё равно не прочесть;
- клетка возилась через `background-position`, то есть перекрашивалась
  целиком на каждом кадре, — теперь её двигает `transform`, округлённый до
  шага клетки, и картинка та же до пикселя, а перерисовки нет;
- `perspective` на обёртке заводила трёхмерный контекст для всей страницы
  ради наклона листа, которого на тачскрине и так нет.

Теперь прогиб виден всегда (свет идёт за пальцем), а буквы ведёт, когда
страница стоит: `scripts/scorrimento.mjs` листает страницу дважды — с
бумагой и без — и падает, если отношение времени кадра больше 1,6. Проверено
на старой версии: она эту проверку не проходит (3,06).

Одной этой проверки мало: её порог проходит и бумага, которая не делает
ничего, — мёртвый прогиб не стоит ничего. Поэтому рядом стоит встречная,
`e2e/materia.spec.ts`: лист гнётся под пальцем, распрямляется, отпущенный, и
не считается, пока страница едет. Она тоже проверена на заведомо сломанном:
прогиб, отключённый одной строкой, её не проходит.

**Прогиб бумаги грузится по первому касанию.** Он существует затем, чтобы
отвечать на палец, а стоит около двухсот миллисекунд работы на замедленном
телефоне — и раньше они приходились ровно на то время, когда читатель
пытается начать читать.

## Спираль

Тема встречается несколько раз, с растущей глубиной. Виток объявляет свои
цели и наследует чужие (`inherits`), а `curriculum()` собирает из этого два
порядка: `readingOrder` — как курс задуман, `spiralOrder` — как его стоит
проходить (сперва все первые витки, потом все вторые).

Связность проверяется **при сборке**: несуществующая тема, осиротевшая тема,
цикл в зависимостях, битая ссылка на виток — всё это роняет сборку, а не
доезжает до читателя. См. `src/content/graph.ts` и `src/courses/index.ts`.

Editorial-стандарт содержания тоже проверяется тестом
(`src/courses/courses.test.ts`): у каждого витка есть работа, есть прибор или
схема, и не меньше полутора тысяч знаков прозы. «Два абзаца и тест» не
собирается.

## Как добавить содержание

Виток — это список блоков:

```ts
{
  depth: 2,
  title: 'Знак связи',
  objectives: ['различать отрицательную и положительную связь'],
  inherits: ['feedback:1'],
  lecture: [
    prose({ text: 'Внутри работает разметка строки: **термин**, ' +
                  '[ссылка на виток](variety:1), $$H = −Σ p log p$$.' }),
    loop({ title: 'Найдите, где контур срывается', delay: 4 }),
    question({ number: 1, question: { kind: 'choice', /* … */ } }),
  ],
}
```

Все виды блоков со своими примерами — на странице `/blocchi/`; она строится
по реестру, так что новый блок появляется там сам.

## Как добавить прибор

1. Расчёт — в `src/widgets/models/`, без единого обращения к DOM, и тесты к
   нему. Это та часть, которая может быть неверной незаметно.
2. Элемент — в `src/widgets/`, наследник `Widget<P>`; цель, если она есть,
   сообщается через `riporta()`.
3. Регистрация — в `src/blocks/interattivi.ts`: схема, `tag`, `load`,
   `reserve`.
4. Строка в `src/scripts/isole.ts` — иначе тест напомнит.
5. Пример в `src/blocks/esempi.ts` — иначе тест напомнит и об этом.

## Без сети

`scripts/offline.mjs` обходит собранный `dist/`, составляет опись и пишет
`sw.js` с ней внутри; отпечаток описи становится именем хранилища, так что
обновление тетради — это новое хранилище и разовая дозагрузка, а не разбор,
что устарело. Тетрадь целиком — около 0,8 МБ.

Опись нельзя написать руками (имена кусков содержат отпечатки), и нельзя
обойтись кэшированием «что попросят»: тогда читатель остаётся без страниц,
куда не заходил, а обещано, что работает всё.

Одна ловушка стоила отдельного расследования и записана в коде служителя:
`caches.match` зовётся с `ignoreVary: true`, потому что опись кладётся
запросами самого служителя (без `Origin`), а документ просит шрифты и модули
в режиме CORS (с `Origin`). Сервер отдаёт `Vary: Origin` — и без `ignoreVary`
страница открывается без сети, но без шрифтов и без приборов.

## Приложение Android (TWA)

Сайт умеет работать как приложение без адресной строки. Для этого он должен
подтвердить, что приложение — своё:

```
TWA_PACKAGE=ru.example.quaderno \
TWA_FINGERPRINT=AA:BB:… npm run build
```

Отпечаток — SHA-256 сертификата подписи (`keytool -list -v -keystore …` или
«Целостность приложения» в Play Console); их может быть несколько, тогда через
запятую. Без этих переменных `.well-known/assetlinks.json` не пишется, и это
не ошибка: приложение просто ещё не выпускали. Сам пакет собирается
`bubblewrap init --manifest https://…/manifest.webmanifest`.

## Выкладка

`.github/workflows/pages.yml`: типы, модульные проверки, сборка с
`PAGES_BASE=/Courses/`, сквозные проверки по этой сборке — и только потом
выкладка в ветку `gh-pages`. Непроверенное не выкладывается.
