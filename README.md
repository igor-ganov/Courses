# Cybernetica

Офлайн-первая интерактивная платформа для изучения кибернетики: глубокие лекции,
работающие симуляции, 3D-визуализации, тактильные схемы и мини-игры, в которых
понятие сначала встречается в действии и только потом получает определение.

Обкатана на вводном курсе **«Кибернетика: введение»** — 4 модуля, 9 тем,
17 витков спирали, около 90 000 знаков материала.

---

## Что это

- **Спиральная программа.** Сначала все темы проходятся на первом уровне
  глубины, затем те же понятия возвращаются с новым аппаратом. Уровни явно
  наследуют цели друг друга (`inherits`) и ссылаются на связанные лекции — как
  назад, так и вперёд по курсу.
- **Интерактив вместо иллюстраций.** Тринадцать интерактивных компонентов, от
  ПИД-контура с запаздыванием до аттрактора Лоренца в 3D. Все они засчитываются
  в прогресс и могут выступать в роли заданий проверки.
- **Прогресс в игровой форме.** Опыт, шесть рангов, награды, серии дней,
  владение темой как скользящее среднее и очередь интервального повторения.
- **Полностью офлайн.** Приложение целиком precache-ится service worker'ом, а
  весь прогресс хранится на устройстве. Ни одного сетевого запроса при работе.
- **PWA/TWA.** Устанавливается как приложение; манифест, иконки и
  `.well-known/assetlinks.json` для Android-обёртки на месте.
- **Всё покрыто тестами.** 267 модульных и компонентных тестов + 14 сквозных,
  включая проверку работы без сети. Контент проверяется тестами наравне с кодом.

## Быстрый старт

```bash
npm ci
npm run dev          # разработка
npm test             # модульные и компонентные тесты
npm run test:e2e     # сквозные тесты (Playwright, на production-сборке)
npm run typecheck    # проверка типов
npm run build        # сборка
npm run icons        # перегенерировать иконки PWA
```

### Публикация

Workflow `.github/workflows/deploy.yml` при каждом пуше прогоняет типы, тесты,
сборку и сквозные тесты, а затем публикует результат в GitHub Pages.

**Один раз потребуется ручное действие:** в репозитории откройте **Settings →
Pages → Source: GitHub Actions**. Токен Actions не может включить Pages сам —
этот вызов требует прав администратора репозитория, поэтому до включения шаг
публикации будет падать с ошибкой `Get Pages site failed`, а тесты — проходить.
После включения запустите workflow заново (Actions → последний запуск →
Re-run jobs), и сайт появится по адресу
`https://<владелец>.github.io/<репозиторий>/`.

Сайт по умолчанию собирается для адреса `/<имя-репозитория>/`. Для собственного
домена задайте `BASE_PATH=/`.

## Архитектура

```
src/
├── core/schema.ts        валидация без зависимостей: контент — это данные
├── content/
│   ├── model.ts          курсы → модули → темы → уровни → лекции из блоков
│   ├── registry.ts       ЕДИНСТВЕННАЯ точка расширения: схема + компонент
│   ├── graph.ts          наследование, ссылки, порядок, разблокировка
│   ├── BlockRenderer.tsx отрисовка дерева блоков с изоляцией ошибок
│   ├── inline.tsx        мини-разметка для текста лекций
│   └── blocks/           библиотека текстовых и учебных блоков
├── engine/
│   ├── assessment.ts     типы вопросов, чистые оценщики, частичный балл
│   ├── questions.tsx     представления вопросов
│   ├── Quiz.tsx          прохождение проверки
│   └── progress.ts       опыт, ранги, владение, повторение, награды
├── widgets/              интерактивные компоненты
│   ├── models/           чистая математика симуляций (тестируется отдельно)
│   └── three/            3D-сцены, загружаются лениво
├── ui/                   оболочка, страницы, стили
└── courses/              собственно материал
```

Подробности для авторов курсов — в [`docs/AUTHORING.md`](docs/AUTHORING.md),
устройство платформы — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Добавить новый интерактивный компонент

Ровно три шага, движок при этом не меняется:

```tsx
// 1. Опишите схему параметров и компонент
const schema = s.object({ title: s.withDefault(s.string(), 'Моя модель'), n: s.number({ min: 1 }) });

export const myBlock = defineBlock({
  type: 'sim.my-model',
  category: 'simulation',
  schema,
  scorable: true,               // умеет отдавать результат в прогресс
  cost: 5,                      // минут изучения
  component: ({ props, ctx, blockId }) => {
    const { done, reach } = useGoal(ctx, blockId);
    return <WidgetShell title={props.title} goal={{ text: 'достичь цели', done }}>…</WidgetShell>;
  },
});

// 2. Внесите в src/content/blocks/index.ts
// 3. Используйте в курсе по строке type
{ id: 'demo', type: 'sim.my-model', props: { n: 4 } }
```

Тесты сразу начнут проверять, что параметры блока во всех курсах валидны, а
галерея на `/#/blocks` покажет его вместе с описанием схемы.

## Установка как приложения

**PWA.** Откройте сайт и выберите «Установить приложение» в браузере. После
первого открытия всё содержимое лежит в кэше — интернет больше не нужен.

**TWA (Android).** Соберите обёртку, например через
[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap), укажите адрес
опубликованного сайта, затем впишите package name и SHA-256 отпечаток
подписи в `public/.well-known/assetlinks.json` и переопубликуйте сайт — без
этого файла Android покажет адресную строку вместо полноэкранного приложения.
